## 摘要
大型睡眠研究数据库包含丰富的时间戳生理注释，但队列发现通常仍通过特定脚本或标量索引过滤器实现。我们提出一种基于逻辑的时间队列发现引擎，将形式语义、模型检验、专门索引和实证评估统一到生物医学信息学框架中。我们采用有理数集成逻辑（QEL）作为睡眠数据查询的稠密时间形式基础，并将每个带注释的多导睡眠图表示为生物医学事件结构时间模型（BEST），即从事件标签到不重叠有理数区间集的有穷映射。队列发现被形式化为在BEST数据库上对QEL公式进行模型检验。我们将常见睡眠研究需求组织为三种可重用的时间查询模式：单事件检索、双事件时间模式匹配和事件数据提取。原型队列发现引擎使用Python实现，支持内存和MongoDB后端执行模式，并在包含多达9000万个区间的合成区间数据集以及来自克利夫兰儿童睡眠与健康研究（CCSHS）的真实世界国家睡眠研究资源注释（包含515名受试者、202,587个区间、23个事件标签）上进行评估。2DFC以线性空间和线性构建时间构建索引，将9000万个区间的构建时间从RTFC的11,549秒和2DRT的23,902秒减少到3,655秒。在CCSHS上，队列选择查询在原生规模下亚秒级延迟，在1000倍规模下低于45秒。本工作是通讯作者倡导的符号生物医学计划的一部分。

## Abstract
Large sleep-study repositories contain rich time-stamped physiological annotations, but cohort discovery is still commonly implemented as ad hoc scripts or scalar-index filters. We present a logic-based temporal cohort discovery engine that brings formal semantics, model checking, specialized indexing, and empirical evaluation into a unified biomedical informatics framework. We adopt Rational Ensemble Logic (QEL) as a dense-time formal foundation for sleep-data querying and represent each annotated polysomnogram as a Biomedical Event Structure Temporal Model (BEST), a finite mapping from event labels to non-overlapping rational interval ensembles. Cohort discovery is formulated as model checking of QEL formulas over BEST databases. We organize common sleep-research requirements into three reusable temporal query patterns: single-event retrieval, dual-event temporal pattern matching, and event data extraction. The prototype cohort discovery engine was implemented in Python with in-memory and MongoDB-backed execution modes and evaluated on synthetic interval datasets containing up to 90 million intervals and on real-world National Sleep Research Resource annotations from the Cleveland Children's Sleep and Health Study (CCSHS) containing 515 subjects, 202,587 intervals, 23 event labels. 2DFC constructs indexes in linear space and linear build time, reducing build time at 90 million intervals from 11,549 s with RTFC and 23,902 seconds with 2DRT to 3,655 seconds. On CCSHS, cohort-selection queries executed at sub-second latency at native scale and under 45 seconds at 1,000 times scale. This work is a part of the Symbolic Biomedicine program championed by the corresponding author.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：  
  - 采用**有理数集成逻辑（QEL）** 作为稠密时间逻辑基础，支持事件标签、持续时间阈值、有界时间窗口、存在/全称量词以及布尔组合。  
  - 每个带注释的多导睡眠图（PSG）表示为**生物医学事件结构时间模型（BEST）**，即从事件标签到不重叠有理数区间集的有穷映射。  
  - 队列发现被形式化为**模型检验**：一个受试者属于某个队列当且仅当其BEST满足给定的QEL公式。

- **关键技术细节**：  
  - **QEL语法与语义**：原子命题p、精确位移φ<sub>u</sub>、有界存在◇<sub>t</sub>φ、有界全称□<sub>t</sub>φ、量词∃x/∀x。时间域为非负有理数ℚ≥0。

  - **三种可重用查询模板**：  
    1. 单事件检索（如“某个标签在时间窗口内是否存在”）  
    2. 双事件时间模式匹配（如“A在B之前结束”、“A与B共现”）  
    3. 事件数据提取（如“返回与某事件重叠的所有其他事件”）

- **索引算法**：  
  - **2DFC（二维分式级联）**：利用BEST中每个标签的区间已排序且不重叠的性质，将每个标签的起点和终点列表分别构建为两个一维分式级联结构（1DFC）。构建时间O(n)，空间O(n)。查询时通过两次1DFC查询定位候选区间范围，复杂度O(log n + m + k)（m为标签数，k为结果数）。  
  - **FCFC（全连接分式级联）**：专为双事件模式匹配设计。将所有事件的区间端点合并为一个全局有序边界数组，并预计算每个标签在每一边界处的“下一个起始”和“下一个活跃”指针。查询时对每个锚点事件可在O(1)时间内找到目标事件的候选区间，避免重复的平铺-排序-扫描操作。

### 8. 不足与局限

1. **假设条件**：2DFC和FCFC均假设每个标签的区间已**排序且不重叠**。若原始注释中存在重叠（如不同评分员标注或非归一化数据），需要额外预处理或标签间去重，增加开销。  
2. **FCFC空间代价**：全局边界索引大小为O(m×l)（m为标签数，l为区间总数），当标签数很大（如数百种）且区间密集时，存储需求可能过高。论文提及稀疏或按需构建可缓解，但未实现。  
3. **通用QEL嵌套公式的效率**：当前框架主要支持论文定义的三种模板；完全通用的、多层嵌套的QEL公式需要递归调用有限证据定理，查询优化和自动计划选择尚未完成，可能在高复杂公式下性能退化。  
4. **只针对静态数据集**：索引（2DFC/FCFC）在添加新事件或新受试者时需**重建**，不支持增量更新，不适合持续增长的流式数据。  
5. **无深度学习对比**：论文未与近期基于深度学习的时序特征提取方法（如Transformer或CNN）进行对比，但这些方法通常用于建模而非精确队列检索，因此对比意义有限，但可作为未来工作。  
6. **跨研究词汇兼容性**：不同睡眠研究可能使用不同的事件标签名和评分规则，论文未深入探讨QEL公式的**跨库迁移**和**语义映射**问题。  
7. **不确定性处理**：注释评分可能存在人为主观差异或信号噪声，当前框架仅处理确定性区间，未集成概率或模糊区间模型。
