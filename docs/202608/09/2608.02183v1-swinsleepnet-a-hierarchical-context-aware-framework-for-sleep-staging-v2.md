## 摘要
自动睡眠分期在睡眠障碍诊断、睡眠质量评估和长期健康监测中起着关键作用；然而，现有方法在模糊和过渡相关的睡眠阶段上表现不佳，原因是对于细粒度的epoch内结构和复杂的跨区域频谱依赖建模不足。传统的epoch级编码器通常无法提取细微的时间微结构和epoch内跨区域交互，导致对困难类别（如N1期）的识别准确率不令人满意。为了解决这些缺点，我们提出了SwinSleepNet，一种层次化上下文感知的双流框架，分别优化epoch内表示学习和epoch间上下文建模。具体来说，我们从两个互补的角度描述每个睡眠epoch：原始时域EEG信号及其时频变换。时域分支采用卷积编码器捕获精细的波形时间细节，时频分支使用Swin Transformer提取局部谱时特征、层次化多尺度信息和长距离空间依赖。多分支提取的特征被融合为集成嵌入，通过双向上下文模块进行优化，以捕获跨epoch的时间依赖性，用于最终的睡眠分期分类。在Sleep-EDF-20、Sleep-EDF-78和SHHS数据集上的综合实验验证了我们的方法实现了具有竞争力的整体性能，并在困难的N1阶段和过渡epoch上表现出更强的鲁棒性和稳定性。结果证明，基于层次化架构的优化epoch内表示学习极大地有益于自动睡眠分期任务。

## Abstract
Automatic sleep staging is a critical role in sleep disorder diagnosis, sleep quality assessment, and long-term health monitoring; however, existing approaches suffer poor performance on ambiguous and transition-related sleep stages, caused by inadequate modeling of fine-grained intra-epoch structures and complex cross-region spectral dependencies. Traditional epoch-level encoders commonly fail to extract subtle temporal microstructures and intra-epoch cross-region interactions, resulting in unsatisfactory recognition accuracy for hard categories such as the N1 stage. To tackle these drawbacks, we propose SwinSleepNet, a hierarchical context-aware dual-stream framework that separately optimizes intra-epoch representation learning and inter-epoch contextual modeling. Concretely, we characterize each sleep epoch from two complementary perspectives: raw time-domain EEG signal and its time-frequency transformation. The time-domain branch adopts convolutional encoders to capture fine waveform temporal details, and the time-frequency branch uses Swin Transformer to extract local spectro-temporal features, hierarchical multi-scale information and long-range spatial dependencies. The multi-branch extracted features are fused into integrated embeddings, which are optimized by a bidirectional context module to capture cross-epoch temporal dependencies for final sleep stage classification. Comprehensive experiments on Sleep-EDF-20, Sleep-EDF-78 and SHHS datasets verify that our method achieves competitive overall performance, and exhibits stronger robustness and stability on difficult N1 stages and transitional epochs. The results prove that optimized intra-epoch representation learning based on hierarchical architecture greatly benefits automatic sleep staging tasks.

- **现有方法的不足**：
  - 大多数现有深度学习方法（CNN、RNN、Transformer等）虽然引入了跨epoch的上下文建模，但**epoch级表示学习仍依赖传统卷积或循环编码器**，难以捕捉单epoch内细粒度的局部时间微结构（如纺锤波、K复合波、慢波活动）和跨区域频谱依赖性。
  - **过渡阶段（尤其N1期）** 持续时间短、判别特征弱、与相邻阶段高度重叠，是公认的最难分类的类别，现有模型对此表现不佳。
  - 在多视图/双分支框架中，最终性能受限于各分支epoch级表示的质量——**epoch级编码器能力不足成为整个层次化框架的性能瓶颈**。
- **核心研究问题**：在层次化睡眠分期框架中，如何在保留跨epoch上下文建模优势的同时，显著增强单epoch表示学习质量，从而提升困难阶段（N1）和过渡期epoch的识别效果？

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想
- 将睡眠分期**显式解耦为两个层次**：① epoch内结构表示学习；② epoch间上下文依赖建模。
- 提出**双流互补视图**策略：同一epoch同时从原始时域信号和时频表示两个视角进行表征，利用两类特征空间的互补性。
- 关键创新点：在**时频分支中引入Swin Transformer**作为epoch编码器，以增强局部频谱-时间模式、跨区域依赖和多尺度结构的建模能力；时域分支则保持卷积结构以维持归纳偏置和结构多样性。

### 2.2 输入表示与序列构造
- 原始EEG记录被分割为N个非重叠的30秒epoch：**X = {x₁, x₂, ..., x_N}**。
- 采用滑动窗口策略构建局部序列，以中心位置i为中心，序列长度为**M = 2k + 1**（实验中M = 21，即k = 10），预测目标为**中心epoch**的睡眠阶段。
- 每个epoch构造两个视图：
  - 原始时域表示：**x_raw ∈ R^(C×L)**，保留精细波形细节。
  - 时频表示：**x_tf ∈ R^(F×T)**，通过短时傅里叶变换（STFT）生成频谱图，描述频谱随时间的演化。

### 2.3 双流Epoch表示学习
- **原始信号分支**：堆叠一维卷积层、归一化层和非线性激活，捕捉幅度变化、短期振荡、瞬态事件等波形级时间结构。刻意保持卷积结构而不使用Transformer，以**保持两个分支的结构差异性**，增强融合时的互补性。
- **Swin Transformer时频分支**（核心组件）：
  - 输入频谱图先经**Patch Embedding**划分为局部patch并投影为token序列：**u⁰ = PatchEmbed(x_tf)**。
  - 经过多个Swin Transformer块，交替使用**窗口自注意力（W-MSA）**和**移位窗口自注意力（SW-MSA）**：
    - W-MSA：在非重叠窗口内建模局部依赖；
    - SW-MSA：通过移位窗口建立跨窗口信息交互。
  - 通过**Patch Merging**实现层次化多尺度特征提取：浅层保留细粒度局部模式，深层整合广域结构关系。
  - 最终通过全局聚合得到epoch级时频表示**h_tf**。
- **双流特征融合**：采用特征拼接后接线性投影：**e_j = W_f·[h_raw ∥ h_tf] + b_f**。刻意选择简单稳定的融合方式，使主要贡献集中在表示增强上而非融合机制。

### 2.4 跨Epoch上下文建模
- 将融合嵌入序列 **E_i = [e_{i-k}, ..., e_i, ..., e_{i+k}]** 输入**双向GRU（BiGRU）**模块，获得上下文增强表示 **Z_i**。
- BiGRU的三个功能角色：① 建模时间依赖和阶段转换模式；② 利用邻域上下文补偿局部证据不足；③ 提升最终预测序列的稳定性和生理合理性。
- 该模块被定位为"**序列级校正器**"——不引入过强的高容量序列骨干，避免偏离"以epoch级增强为核心"的研究焦点。

### 2.5 分类与优化目标
- 对中心epoch的上下文增强表示 **z_i** 应用线性分类器 + Softmax：**p̂_i = Softmax(W_c·z_i + b_c)**，预测标签为 **ŷ_i = argmax p̂_i**。
- 训练损失为中心epoch的**交叉熵损失**。
- 整体计算路径：**x_raw, x_tf → h_raw, h_tf → e → z → ŷ**，所有模块端到端联合优化。

## 6. 主要结论与发现

- **整体性能**：在Sleep-EDF-20上达到89.9% ACC / 85.6% MF1 / 0.863 κ；在Sleep-EDF-78上87.7% / 83.7% / 0.831；在SHHS上89.7% / 84.1% / 0.855——全面超越对比方法，且在三个不同规模数据集上保持一致优势。
- **困难阶段改善显著**：N1期和过渡epoch的识别明显提升，这是最难获得的改进，直接验证了增强epoch级表示学习的价值。
- **上下文建模仍不可替代**：消融表明去掉BiGRU上下文模块后Macro-F1下降明显（Sleep-EDF-20上ACC从88.2%降至86.4%，MF1从82.9%降至80.5%），说明局部表征与时间上下文是互补关系。
- **Swin Transformer是主要增益来源**：在时频分支中用Swin替换CNN后，ACC从87.0%提升至88.2%，MF1从81.2%提升至82.9%，且Macro-F1的增益大于ACC的增益，说明其特别有利于困难类别。
- **双流互补性得到验证**：双流融合优于任一单分支；简单拼接已足够好，交叉注意力有额外小幅增益（88.6%/83.5% vs 88.2%/82.9%），说明性能提升主要来自分支自身质量而不过度依赖融合机制。
- **辅助监督稳定优化**：同时施加两个分支的辅助损失效果最佳（λ_aux = 0.3）。
- **总体判断**：层次化框架中强化epoch级表示学习是提升睡眠分期准确性和鲁棒性的有效方向。

## 7. 优点

- **问题定位精准**：明确指出层次化分帧中epoch级编码器是性能瓶颈，而非单纯堆叠更大模型或更复杂上下文模块，针对性很强。
- **保留归纳偏置的深思熟虑**：时域分支保持卷积、时频分支使用Swin Transformer，不是简单"一刀切"地全部替换为同一架构，而是利用不同表示空间的结构差异增强互补性，设计动机清晰。
- **Swin Transformer的选择合理**：睡眠频谱图中的判别模式本质上是局部化、结构化的（纺锤波、K复合波等），Swin的窗口注意力和移位窗口机制恰好匹配这种局部建模+跨区域交互的需求，计算开销也比全局自注意力更优。
- **层次化解耦清晰完整**：epoch级增强→双流融合→上下文校正→中心epoch分类，形成了完整的"局部证据增强+序列级校正"决策闭环，与睡眠分期的生理本质（阶段连续性与转换规律）高度对齐。
- **实验规模可观**：3个数据集（20→78→329名受试者）、10+种对比方法、5组系统消融、参数敏感性分析和可视化分析，覆盖面较广。
- **刻意简化融合和上下文模块**：将注意力集中在表示增强这一核心贡献上，避免复杂融合/序列模块干扰结论归因，体现了良好的科研设计品味。

- **未见真实临床数据验证**：仅在公开数据集上评估，未涉及睡眠障碍患者（如失眠、呼吸暂停）等多样化临床队列，泛化性到真实临床环境有待验证。
