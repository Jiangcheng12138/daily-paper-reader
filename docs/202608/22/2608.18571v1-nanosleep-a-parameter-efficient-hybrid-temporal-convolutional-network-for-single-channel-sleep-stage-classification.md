## 摘要
基于单通道脑电图（EEG）的睡眠阶段分类对于可穿戴设备和家庭睡眠监测至关重要。然而，许多深度学习模型以牺牲模型大小为代价实现高精度，这限制了它们在资源受限设备上的部署。在本工作中，我们提出了NanoSleep，一种用于自动睡眠阶段分类的紧凑型混合时间卷积网络。NanoSleep结合了可学习的Sinc卷积前端、融合多尺度时间和频谱表示的双分支特征提取器、具有通道校准的门控扩张时间卷积骨干网络，以及用于序列级解码的条件随机场。我们进一步采用加权校准焦点损失来解决类别不平衡问题。我们使用受试者交叉验证在Sleep-EDF和Sleep-EDF-Expanded数据集上评估NanoSleep。所提出的模型 consistently 优于六种代表性基线方法，消融研究确认了每个主要组件的贡献。这些结果表明，NanoSleep在准确性和效率之间提供了有效的平衡，使其非常适合可穿戴设备、家庭睡眠监测和资源受限的临床应用。

## Abstract
Sleep stage classification from single-channel electroencephalography (EEG) is essential for wearable and home-based sleep monitoring. However, many deep learning models achieve high accuracy at the cost of large model sizes, which limits their deployment on resource-constrained devices. In this work, we present NanoSleep, a compact hybrid temporal convolutional network for automatic sleep stage classification. NanoSleep combines a learnable Sinc-convolutional front end, a dual-branch feature extractor that fuses multi-scale temporal and spectral representations, a gated dilated temporal convolutional backbone with channel recalibration, and a conditional random field for sequence-level decoding. We further employ a weighted calibrated focal loss to address class imbalance. We evaluate NanoSleep on the Sleep-EDF and Sleep-EDF-Expanded datasets using subject-wise cross-validation. The proposed model consistently outperforms six representative baseline methods, and an ablation study confirms the contribution of each major component. These results demonstrate that NanoSleep provides an effective balance between accuracy and efficiency, making it well suited for wearable devices, home-based sleep monitoring, and resource-constrained clinical applications.

## 1. 核心问题与整体含义（研究动机与背景）

- 睡眠是维持记忆巩固、免疫调节和认知代谢功能的关键生理过程，睡眠障碍与心血管疾病、认知衰退及多种神经精神疾病密切相关。因此，准确评估睡眠对临床诊断和管理至关重要。
- 临床金标准多导睡眠监测（PSG）需要专业实验室、昂贵设备及多电极佩戴，且人工分期耗时费力，评分者间一致性常低于90%。因此，自动睡眠分期系统成为研究热点，而单通道EEG因其硬件简单、舒适度高、保留大部分分期相关信息，特别适合可穿戴和家庭监测场景。
- 现有深度学习模型面临三大挑战：
  1. **计算效率低**：高精度模型（如SleepEEGNet约2.6M参数、XSleepNet约5.8M参数）参数量大，难以部署在可穿戴设备和资源受限的临床硬件上；现有轻量模型常在缩减体积时牺牲精度。
  2. **类别不平衡**：睡眠数据中N1阶段样本极少，多数模型对该少数类表现不佳。
  3. **序列建模不足**：许多方法独立分类每个epoch，忽略睡眠阶段生理转换规律，易产生孤立的、生物学上不合理的预测。
- 针对上述问题，论文提出**NanoSleep**——一种紧凑型混合时间卷积网络，目标是在高精度与小体积之间取得最佳平衡，适用于可穿戴设备、家庭监测和资源受限的临床应用。

## 2. 方法论：核心思想与关键技术细节

NanoSleep的总体流程为：预处理 → 时间域/频谱双分支特征提取 → 特征融合 → 门控膨胀TCN骨干 → CRF序列解码 → 睡眠分期输出。

### 2.1 预处理管道
- **可学习Sinc滤波器前端**：用可学习Sinc卷积层取代固定带通滤波器。每个滤波器仅学习低截止频率f₁和高截止频率f₂两个参数，通过两个sinc函数之差构造时域滤波器响应，在极低参数开销下实现对数据驱动的最优频带选择。
- **鲁棒归一化**：用中位数和中位数绝对偏差（MAD）替代均值和标准差进行归一化，降低EEG高幅伪迹的影响、减少受试者间幅度差异。
- **小波去噪**：采用Daubechies-4小波、4层分解和通用软阈值，去除低幅噪声，同时保留睡眠纺锤波和K复合波等重要临床波形。

### 2.2 双分支特征提取器
- **多尺度时间域分支**：三个并行1D卷积核（大小分别为7、25、51）并行处理，分别捕捉短时瞬态事件（如K复合波）、中等时长节律（如睡眠纺锤波）和慢波等长时间模式，输出拼接形成多尺度时间特征。
- **频谱特征分支**：计算标准delta、theta、alpha、beta频带的相对功率谱密度（降低受试者间幅度差异的敏感性）、多尺度散布熵以及Hjorth参数（活动度、移动度、复杂度），经由小型MLP（两层，64和32神经元，ReLU激活）转换为紧凑特征向量。该手工特征分支提供稳定的生理学可解释信息，跨受试者泛化能力强。

### 2.3 特征融合
- 将时间分支与频谱分支的输出拼接成统一表示，同时利用学习特征的灵活性和手工特征的鲁棒性，并保留频谱特征的生理可解释性。

### 2.4 门控膨胀时间卷积骨干
- 六个残差块，膨胀率分别为1、2、4、8、16、32，核大小为7，64个特征通道。膨胀卷积在不增加参数和避免顺序计算的前提下扩大感受野，捕捉跨epoch的长程时间上下文。
- 每层包含**门控线性单元（GLU）**，学习保留或抑制哪些时序信息；随后应用**挤压激励（SE）模块**（通道压缩比8）对特征通道进行重校准，突出信息量高的通道，抑制低效通道。

### 2.5 序列级解码：线性链CRF
- 睡眠阶段遵循既定的生理转换模式（如深睡直接转为REM不常见）。CRF学习一个5×5的转移矩阵，对候选标注序列打分：

\[
s(y) = \sum_{t=1}^{T} U_t(y_t) + \sum_{t=1}^{T-1} A(y_t, y_{t+1})
\]

其中Uₜ(yₜ)是骨干网络在第t个epoch对阶段yₜ的一元分数，A(yₜ, yₜ₊₁)是相邻阶段间的可学习转移分数。推理时使用**Viterbi算法**求最高分标注序列，从而抑制孤立的生理学不合理预测（如深睡周期中单个觉醒epoch）。

### 2.6 训练目标
- **加权校准焦点损失**：
  \[
  L_{focal} = -w_c (1-p_c)^{\gamma_c} \log(p_c)
  \]
  - 类别权重采用逆类别频率的次线性函数，在不过度忽视多数类的前提下加权少数类；
  - 类别特定聚焦参数：N1和N3设为2.5，W/N2/REM设为1.0；
  - 概率平滑（平滑因子0.1）用于校准过度自信的预测；
  - 边界感知惩罚：在连续epoch发生睡眠阶段转换时，焦点损失加倍，以提高阶段边界预测准确性。
- 最终训练目标为加权校准焦点损失与CRF负对数似然之和。

## 6. 主要结论与发现

- **Sleep-EDF数据集**：NanoSleep以**86.5%准确率、82.1%宏F1、0.81 kappa**超越所有基线，比最强轻量基线TinySleepNet高出1.1%准确率、1.6% MF1和0.01 kappa，而参数仅为0.35M（TinySleepNet的约27%）；相比高容量模型DeepSleepNet（24.7M参数）高出4.6%准确率。
- **Sleep-EDF-Expanded数据集**：NanoSleep同样保持最优，**84.3%准确率、79.8% MF1、0.78 kappa**，在各阶段F1上取得W、N1、N2、REM四项最佳，表明模型在更大、更多样的群体上具有良好的跨受试者泛化能力。
- **阶段级表现**：W、N2、N3、REM阶段均达到高可靠性（召回率83-94%）；**N1仍是最难阶段**（召回率约47.5-48.5%），主要混淆方向为N1→N2（约26.5-29.5%）、N1→REM（约9-14%）、N1→W（约11.5-12.5%），这与N1作为过渡阶段的生理特性相符；N3与N2之间存在一定混淆（Expanded数据集上16%的N3被判为N2），反映了群体异质性和慢波活动减少的影响。
- **消融实验证实每个组件均有贡献**：去除多尺度卷积（MF1降至76.7%）、去频谱分支（降至77.9%）、去焦点损失（降至79.5%）是影响最大的三项；去CRF降至79.9%、去数据增强降至79.8%、骨干换BiLSTM降至79.8%、去SE降至81.3%。

## 7. 优点

- **极高的参数效率**：仅0.35M参数，远小于现有高精度模型（DeepSleepNet的70分之一、XSleepNet的约16分之一、SleepEEGNet的约7分之一），同时精度全面领先，实现了优异的精度-体积平衡。
- **混合特征设计新颖有效**：将可学习多尺度时间特征与可解释手工频谱特征（频带功率、散布熵、Hjorth参数）互补融合，突破了单纯依赖学习或手工特征的局限性，兼具性能与生理可解释性。
- **预处理环节的创新**：用可学习Sinc卷积替代固定滤波，用中位数/MAD鲁棒归一化替代均值/标准差归一化，结合小波去噪，形成一套对伪迹和个体差异稳健的预处理管道。

- **序列建模的轻量实现**：膨胀卷积+门控+SE通道重校准的骨干比LSTM更高效，CRF解码器有效保证了预测序列的生理合理性，且复杂度极低。
- **实验设计规范**：subject-wise交叉验证、统计显著性检验、与多种架构族系的公平对比、系统化的消融研究，方法严谨透明。
