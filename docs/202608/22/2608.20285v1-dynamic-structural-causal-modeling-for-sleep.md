## 摘要
睡眠呼吸障碍的因果动态是复杂的，并且在不同患者群体之间存在差异，这阻碍了针对性干预措施的发展。我们从家庭睡眠呼吸暂停测试（HSAT）记录中学习睡眠呼吸障碍的动态因果图，揭示了按性别和年龄子队列划分的因果结构中的系统性差异。我们使用PCMCI+算法对从105个HSAT记录中得出的窗口化分数变量进行学习，通过边缘黑名单利用领域知识，并采用自助聚合来解决小子队列规模问题。学习到的图显示，时间自依赖性和呼吸暂停-去饱和关系在所有队列中持续存在，而其他关系则存在显著差异。

## Abstract
The causal dynamics of sleep-disordered breathing are complex and vary across patient populations, hindering the development of targeted interventions. We learn dynamic causal graphs of sleep-disordered breathing from Home Sleep Apnea Test (HSAT) recordings, revealing systematic differences in causal structure across sex and age subcohorts. We do so using the PCMCI+ algorithm on windowed fractional variables derived from 105 HSAT recordings, exploiting domain knowledge via edge blacklisting and employing bootstrap aggregation to address small subcohort sizes. The learned graphs show that temporal self-dependencies and the apnea-desaturation relationship persist across all cohorts, while other relationships vary substantially.

## 一、论文核心问题与整体含义

- **研究背景**：睡眠呼吸障碍（SDB）的病理机制具有显著的动态性和人群异质性——呼吸与心血管机制在一夜之间及不同夜晚均持续变化，且不同患者的病理生理学机制可能不同。这种复杂性阻碍了靶向干预的发展。
- **核心需求**：可靠的动态数据驱动应用系统（DDDAS）需要精确的因果机制模型来支撑临床决策，但单一的人群级模型难以捕捉亚组差异，因此必须理解不同亚群（性别、年龄分层）的因果动态差异。
- **关键瓶颈**：传统多导睡眠监测（PSG）成本高昂，难以大规模获取数据；家庭睡眠呼吸暂停测试（HSAT）虽然更便捷、成本更低，但此前主要被用于诊断评分而非学习机制性模型。
- **研究目标**：利用 HSAT 录音学习 SDB 的**动态因果图**，揭示不同性别和年龄亚组在因果结构上的系统性差异，为未来 DDDAS 系统与个性化干预提供因果组件。

## 二、方法论

**核心思想**：将时间序列因果发现与高阶局部结构上的 bootstrap 聚合相结合，在数据量小的医学场景下学习稳定且有意义的动态因果图。

**关键技术细节**：

1. **动态结构因果模型（DSCM）框架**：扩展 SCM 至时间演化过程，定义元组 M_d = ⟨U, V, T, F, P(U)⟩。时间离散化为时间序列图 G = (V, E, T)，边包含同期依赖 V_t^i → V_t^j 和滞回依赖 V_{t-τ}^i → V_t^k (τ > 0)。
2. **窗口化特征构造**：基于 10 秒分析窗口计算 6 个分数化变量——呼吸暂停低通气事件（A）、去饱和（D）、吸气流量受限（I）、流量受限呼吸努力（F）、脉搏激活（P）、打鼾负担（S）——每个特征表示对应事件占窗口时间的比例。
3. **PCMCI+ 因果发现算法**：以偏相关检验为条件独立性检验，学习滞回与同期因果边，输出矩时条件独立性（MCI）值用于边显著性筛选（阈值 m = 0.03）。
4. **领域知识约束**：由临床专家提供禁忌边集合，以黑名单方式嵌入因果发现过程，用于消解马尔可夫等价类中的方向不确定性。
5. **Bootstrap 与一般模型平均（GMA）**：
   - 从患者轨迹中有放回地采样 b = 100 次；
   - 对每个 bootstrap 样本运行 PCMCI+ 得到因果图；
   - 提取每个顶点与其父节点之间的局部子结构（高阶交互结构）；
   - 计算这些结构的后验概率，过滤低于阈值 α = 1/(|V|-1) = 0.09 的结构；
   - 按后验降序贪心添加边，同时保证无环性约束。

## 六、主要结论与发现

1. **跨亚组稳健的因果关系**：
   - 各特征的时间自依赖（t-1 → t 的滞回边）在所有队列中最为显著；
   - 呼吸暂停事件（A）→ 去饱和（D）的关系在**所有**亚组中均持续存在，验证了这一核心生理机制的一致性。
2. **性别差异**：
   - 女性队列中存在打鼾（S）与吸气流量限制（I）的同窗因果关联（S^{t-1} → S^t ← I^{t-1}），男性中不存在；
   - 男性存在 S^{t-1} → S^t ← A^t 结构（后验 0.24），女性中被拒绝；
   - **流量受限呼吸努力（F）在全部女性样本中恒为 0**，导致该特征完全无法参与女性因果图的学习——作者归因于特征构造对小幅值不敏感。
3. **年龄差异**：
   - 老年组：A^t → S^t ← S^{t-1} 被接受（后验 0.35），因果方向为**呼吸暂停 → 打鼾**；
   - 年轻组：A^{t-1} → A^t ← S^t 被接受（后验 0.24），因果方向为**打鼾 → 呼吸暂停**——因果方向发生逆转。
4. **总体启示**：亚组间的因果结构存在系统性差异（方向反转、边缺失、新边出现），证明**单一整体模型不足以刻画不同人群的睡眠呼吸障碍机制**，动态因果建模可以作为 DDDAS 系统的有效组成部分。

## 七、优点

1. **数据创新**：首次将 HSAT（家庭睡眠呼吸暂停测试）从诊断评分工具拓展为因果机制学习的来源，降低了因果建模对昂贵 PSG 数据的依赖。
2. **方法适配性好**：结合领域知识黑名单解决马尔可夫等价类方向问题，使用高阶局部结构聚合（而非简单边聚合）提升了小样本因果发现的稳定性，这一设计在医学低数据场景中具有实用价值。
3. **临床可解释性**：学习得到的是可解释的因果图，能够明确揭示亚组间的因果方向反转和边缺失，直接产出临床可读的假设。
4. **视角新颖**：明确以 DDDAS 为应用目标，将因果模型作为动态自适应系统的组件，具有方法落地的实际导向。

## 八、不足与局限

1. **样本量小**：105 例记录经性别和年龄分层后，每个亚组仅 20～58 人，因果发现的统计功效有限；bootstrap 只能部分缓解并非彻底解决。
2. **特征覆盖有限**：HSAT 未记录睡眠分期、觉醒等生理相关信息，可能遗漏关键的混杂/中间变量，违反因果充分性假设；F 特征在女性中全为 0 暴露了特征构造灵敏度的不足。
3. **强假设约束**：因果发现依赖平稳性、因果马尔可夫条件、忠实性和因果充分性等假设，但睡眠本身在整夜中随时间变化，平稳性假设显然与实际不符（作者也承认此点）。
4. **实验评估不足**：没有与基线方法（如普通 PCMCI、没有领域约束的版本、简单边聚合）对比，没有定量稳定性或重构精度指标，也没有跨数据集验证，结论的外部有效性有待验证。
5. **方向不确定性**：从观测数据学习因果图只能获得马尔可夫等价类，即使有领域知识约束，部分边的因果方向仍可能有偏差。
6. **临床泛化前景有限**：本研究是单中心、特定 HSAT 设备的数据，研究结论向其他设备和临床环境的推广需要更多验证。
